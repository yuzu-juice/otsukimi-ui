## Accessibility

### Target

WCAG 2.1 AA

### Principles

- Accessible First
- Cute Second
- Clear and Consistent

### Requirements

- Text contrast ratio ≥ 4.5:1
- Visible focus indicators
- Keyboard accessible
- Touch targets ≥ 44×44px
